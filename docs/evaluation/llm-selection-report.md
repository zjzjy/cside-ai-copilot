## 三、推荐梯度

### 🥇 首推：DeepSeek-V4-Pro

- **指令遵从**：国产最高（48.57），对 JSON 约束理解最好
- **成本极低**：单次话术生成约 ¥0.012，MVP 阶段 1000 次测试仅 ¥12
- **风险**：高峰期可能存在算力挤兑、强制降级。需配置备用模型

### 🥈 次选：Qwen3.5-Plus

- **性价比最优**：输入 ¥0.80 + 输出 ¥4.80，单次 ¥0.01
- **中文话术质量最好**：阿里系，中文理解和创作能力国产第一
- **开发者生态最完善**：Spring AI 阿里云 Starter、DashScope SDK 成熟
- **JSON 格式**：略弱于 DeepSeek，但可通过 Prompt 约束 + 后处理兜底

### 🥉 候补：ERNIE-5.1

- **指令遵从国产第二**（47.62），与 DeepSeek 几乎持平
- **中文理解强**：百度在中文 NLP 领域积累最深
- **劣势**：价格偏高（¥8+¥24），单次 ¥0.048
- **适用场景**：DeepSeek 高峰期降级时的备用模型

### 🆕 观察：GLM-5.2

- **2026.06 最新发布，开源 MIT**，753B MoE，编程能力全球 Top 4
- **优势**：SWE-bench 62.1（超 GPT-5.5）、AIME 99.2、Code Arena 全球第 1
- **JSON 输出**：支持 Function Calling + Structured Outputs，但暂无第三方专项评测
- **指令遵从**：评价两极——"像 Claude 一样主动但也因此不听话"，稳定性不如 DeepSeek
- **价格偏高**：¥8+¥28，单次 ¥0.056，成本是 DeepSeek 的 4.7 倍
- **适用场景**：当前不作为首推。待社区 JSON 输出评测数据积累后再评估。如果后续微调或自部署（MIT 开源），值得优先考虑

### 不推荐（针对本项目）

| 模型              | 原因                                                    |
| ----------------- | ------------------------------------------------------- |
| 豆包 Seed-2.0-Pro | JSON 格式化能力差，被实测认为"深层逻辑极度薄弱"         |
| Kimi-K2.6         | 格式遵循好但价格最高（¥27/百万输出），话术场景性价比低 |
| GLM-5.1           | JSON 格式好但指令遵从偏低，且价格高昂                   |
| 混元-TurboS       | 通用能力不足，话术质量存疑                              |

## 四、MVP 推荐方案

```
主模型: DeepSeek-V4-Pro（指令遵从最强 + 成本低）
备用模型: Qwen3.5-Plus（中文话术好 + 成本低）
降级策略: 主模型不可用/超时 → 自动切 Qwen3.5-Plus
```

**Prompt 模板开发阶段**：直接用 DeepSeek-V4-Pro 开发和测试。验证通过后，用同样的 5 条测试用例跑一遍 Qwen3.5-Plus，确认 JSON 输出稳定性无显著差异即可。

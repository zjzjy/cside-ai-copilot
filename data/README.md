# data/ — 数据层

## 目录

```
data/
├── README.md          ← 本文件
├── schema.sql         ← 数据库建表 DDL（PostgreSQL + pgvector）
├── seed/              ← 种子数据（开发/测试用初始数据）
│   ├── README.md
│   ├── common/        ← 通用层（全矩阵共享的通用话术、平台政策）
│   ├── brands/        ← 品牌层（vivo、华为的商品/FAQ/话术模板/品牌配置）
│   └── stores/        ← 店铺层（单店差异化数据，如促销活动）
└── eval/              ← 评测数据集（待填充）
```

## 各文件说明

| 文件/目录 | 用途 | 何时用 |
|-----------|------|--------|
| `schema.sql` | 建库建表，含初始品牌和店铺数据 | 首次搭建本地环境时执行 |
| `seed/` | 导入知识库的种子数据（JSON） | 开发阶段填充RAG知识库 |
| `eval/` | 评测测试集（意图分类、检索评测等） | 技术选型评测时使用 |

## 快速开始

```bash
# 1. 建表
psql -U cside -d cside -f data/schema.sql

# 2. 导入种子数据（后续提供导入脚本）
# 目前 MVP 阶段从 JSON 文件直接读取
```

## 注意事项

- `schema.sql` 中的初始品牌/店铺数据仅用于开发，生产环境需通过管理后台录入
- 种子数据 JSON 文件和数据库表结构保持对应关系，修改 JSON 字段时需同步更新 DDL
- 评测数据集（`eval/`）不导入生产数据库，仅用于离线评测

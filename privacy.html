隐私声明

CSide 静态演示站 · 生效日期：2026-10-19 · 适用网址： https://zjzjy.github.io/cside-ai-copilot/

一句话说明：本站是纯静态的产品演示，不收集、不存储、不上传、不出售任何个人信息；页面中的客户、订单、店铺和商品数据全部是虚构的 Mock 数据。

1. 适用范围

本声明适用于托管在 GitHub Pages 上的 CSide 静态演示站，包括入口页、并排演示页、模拟客服工作台和侧边栏演示页。本声明不适用于你在本地自行运行的 CSide 后端、数据库或浏览器扩展。

2. 我们不收集个人信息

本站不需要注册、登录、支付，也没有会向服务器提交数据的表单。具体来说：

  • 不收集姓名、手机号、邮箱、地址、身份证号、银行卡号等个人信息；
  • 不收集真实客户对话、订单号、店铺经营数据或平台账号；
  • 不设置 Cookie，不使用统计分析、广告、追踪像素或第三方脚本；
  • 不要求你输入任何账号或密码。

3. 页面中的数据都是虚构的

演示页中的客户昵称、聊天内容、订单号、收货地址、商品名称、店铺名称和品牌信息均为界面演示用的虚构数据，不来自任何真实店铺或真实客户。页面展示的品牌名称仅用于说明产品支持多品牌、多平台的客服场景，本站与这些品牌没有隶属或合作关系。

4. 剪贴板

只有当你主动点击“复制”按钮时，浏览器才会在本地把当前展示的话术文本写入剪贴板。该操作不会把内容发送到任何服务器，也不会被本站读取或保存。

5. 浏览器扩展与本地后端

本站只展示静态演示，不安装、不运行浏览器扩展，也不连接本地后端。CSide 浏览器扩展和本地后端是独立的开发工具；如果你另行安装并在自己的电脑上运行它们，其数据处理方式以对应仓库中的说明为准，不属于本站的收集行为。

6. 托管服务

本站由 GitHub Pages 提供静态托管。GitHub 可能按照其自身的隐私声明处理标准的访问日志（例如 IP 地址、浏览器类型和访问时间）。本站不接入、不读取、不分析这些日志，也不会将其用于识别个人身份。

7. 儿童隐私

本站是面向开发者和产品演示的静态页面，不面向儿童，也不会有意收集儿童的个人信息。

8. 声明更新

如果本站的功能或数据处理方式发生变化，我们会更新本页面并修改生效日期。当前版本为 2026-10-19。

9. 联系方式

如对本声明有疑问，可以通过项目仓库的 Issues 联系： https://github.com/zjzjy/cside-ai-copilot/issues

English summary

This is a static product demo hosted on GitHub Pages. The site does not collect, store, transmit, or sell personal information. It has no account registration, login, payment, or data-submission forms, and it does not use cookies, analytics, advertising, tracking pixels, or third-party scripts. All customer, order, store, product, and brand data shown in the demo are fictional mock data.

The clipboard is written locally only when you explicitly click a copy button. The public site does not install or run the browser extension and does not connect to a local backend. GitHub Pages may process standard access logs under GitHub's own privacy statement; this site does not access or analyze those logs.

Questions: project Issues.
